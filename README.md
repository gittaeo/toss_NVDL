# NVDL 원화 구간 매매 감시기

토스증권 공식 Open API를 사용하는 Python 3.10+ 프로그램입니다. 기본 설정은 **모의 실행**이며 주문을 보내지 않습니다.

## 전략

- 미보유 상태에서 원화 환산 가격이 40,000~40,500원에 있으면 USD 현금 매수 가능 금액의 99%로 시장가 매수 (`cash_buffer_percent` 조정 가능)
- 보유 상태에서 원화 환산 가격이 50,000원 이상이면 보유 NVDL의 매도 가능 수량 전량을 시장가 매도 (가격이 55,000원을 넘어도 매도)
- 4만 원 아래에서는 보유 수량을 매도하지 않고 새 매수도 하지 않음
- 주문이 완료되고 미보유 상태로 돌아오면 다음 매수 기회를 기다림
- 구간 밖에서는 대기

원화 환산 가격은 토스증권의 NVDL 달러 현재가 × USD/KRW 환율 `rate`로 계산하고 1원 미만을 버려 구간을 판단합니다. 앱에 표시되는 원화 추정가나 실제 환전 금액과 차이가 날 수 있습니다. 시장가 주문의 체결가는 감지한 시세와 다를 수 있습니다.

## 준비

1. `config.example.json`을 `config.json`으로 복사합니다.
2. 매수·매도 경계를 확인합니다. `live_trading`은 `false`로 둡니다.
3. 토스증권에서 발급한 **client ID와 client secret**을 로컬 환경변수 `TOSS_CLIENT_ID`, `TOSS_CLIENT_SECRET`에 설정합니다. 종합매매 계좌가 둘 이상이면 `TOSS_ACCOUNT_SEQ`도 지정합니다. 비밀키를 코드·설정 파일·채팅에 넣지 마세요.

PowerShell에서는 `./start.ps1`을 실행하면 키를 입력받아 감시기를 시작합니다. 비밀키는 화면에 표시되지 않고 파일에 저장되지 않습니다. 설정은 기본적으로 모의 실행입니다.

오프라인 조건 확인:

```powershell
python bot.py --simulate 30 1400
```

실제 시세를 사용한 모의 실행 1회:

```powershell
python bot.py --once
```

계속 감시:

```powershell
python bot.py
```

설정과 모의 실행을 검토한 뒤 직접 실거래를 켜려면 `config.json`의 `live_trading`을 `true`로 바꿉니다. 프로그램이 실행 중인 컴퓨터와 네트워크가 유지되어야 감시가 계속됩니다.

API는 미국 주식 금액 기반 매수를 USD `orderAmount`로 접수합니다. 이 코드는 USD 매수 가능 금액을 기준으로 최대한 사용합니다. 원화 예수금이 USD 매수 가능 금액에 포함되는지는 계좌 설정과 API 응답으로 확인해야 합니다. 포함되지 않으면 원화 현금을 자동 환전해 매수하지 않습니다.

## 주문 안전장치

- 기존 NVDL 미체결 주문이 있거나 봇의 주문이 처리 중이면 새 주문을 내지 않습니다.
- 주문 요청 결과가 불분명하면 자동 실행을 중단합니다. 토스증권 주문 내역을 확인한 뒤 `state.json`을 점검해야 합니다.
- 시세 시각이 2분 넘게 지났거나 환율 유효기간이 끝났으면 주문하지 않습니다.
- 매도 가능 수량이 없으면 매도하지 않습니다.
- 매매 조건은 보유 여부에 따라 한 번에 한 방향만 평가합니다.
- 실행 전부터 보유한 NVDL도 매도 구간에서는 전량 매도 대상으로 봅니다.
- 금액 기반 미국 주식 시장가 매수와 소수점 매도를 위해 미국 정규장 종료 1시간 전까지만 주문합니다.
